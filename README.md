# Stability of SARS-CoV-2 Variant Classification

This repository contains the computational analysis supporting the MSc dissertation:

**Stability of SARS-CoV-2 Variant Classification Using Supervised Machine Learning Methods and Natural Vector-like Feature Representations**

The analysis compares selected numerical genomic feature representations for supervised SARS-CoV-2 variant classification and evaluates prediction stability using bootstrap resampling.

## Overview

SARS-CoV-2 genomic surveillance has generated large volumes of sequence data. This repository supports a dissertation analysis that examines whether pre-extracted numerical genomic feature representations can classify known SARS-CoV-2 variant labels accurately and whether predictions remain stable when the model development data are resampled.

The repository is organised around one main Jupyter Notebook. The notebook performs data preparation, feature representation checks, supervised machine learning model comparison, final model evaluation and bootstrap-based prediction stability analysis.

## Research Question

How do selected Natural Vector-like feature representations compare in terms of classification performance and prediction stability for selected supervised SARS-CoV-2 variant classification?

## Aim

To compare the classification performance and prediction stability of selected Natural Vector-like feature representations for SARS-CoV-2 variant classification using selected supervised machine learning and bootstrap-based stability assessment.

## Analysis Overview

The analysis workflow is:

```text
Data preparation
→ Feature representation checks
→ Target label and predictor verification
→ Rare class filtering
→ Development/test split
→ Cross-validation model comparison
→ Feature representation selection
→ Classifier selection
→ Final test set evaluation
→ Bootstrap prediction stability analysis
→ Probability instability outputs
→ Classification instability outputs
→ Variant-level stability outputs
→ Exported figures, metrics and reproducibility information
```

The main analysis uses pre-extracted SARS-CoV-2 genomic feature representations and an existing variant or lineage label as the supervised learning target.

## Machine Learning Analysis

The notebook implements supervised multiclass classification using scikit-learn pipelines.

The classifiers evaluated in the notebook are:

| Classifier | Abbreviation |
|---|---|
| Decision Tree | DT |
| Random Forest | RF |
| Gaussian Naive Bayes | GNB |
| k-Nearest Neighbours | KNN |
| Support Vector Machine | SVM |
| Neural Network | NN |
| Logistic Regression | LR |

The analysis uses repeated stratified cross-validation on the development set for feature representation and classifier comparison. The selected classifier is then evaluated on the fixed test set for the selected feature representations.

Key configuration values in the notebook include:

| Setting | Value |
|---|---|
| Random state | `42` |
| Test size | `0.20` |
| Cross-validation splits | `5` |
| Cross-validation repeats | `2` |
| Rare class threshold | `< 30 observations` |
| Bootstrap repetitions | `200` |
| Bootstrap type | Stratified bootstrap |

## Prediction Stability Analysis

The repository includes bootstrap-based prediction stability analysis. For each selected feature representation, the selected classifier is refitted on bootstrap samples from the development set and applied to the same fixed test set.

The stability analysis produces outputs for:

- probability instability;
- classification instability;
- prediction agreement;
- classification switching;
- class-specific stability;
- variant-level stability.

The bootstrap outputs are stored mainly in:

```text
outputs_revised/bootstrap/
outputs_revised/metrics/
```

## Reproducibility

The notebook includes several reproducibility features:

- fixed random state set to `42`;
- one fixed development/test split;
- stratified development/test splitting;
- repeated stratified cross-validation;
- feature and model selection based on development-set evidence;
- test set reserved for final evaluation and bootstrap prediction comparison;
- bootstrap repetitions requested as `200`;
- output tables and figures saved to structured folders;
- runtime reproducibility information saved to `outputs_revised/reproducibility_info.json`.

Reproducibility depends on access to the same pre-extracted feature files. If the feature files are not available, the notebook structure and code can be reviewed, but the full analysis cannot be rerun.
